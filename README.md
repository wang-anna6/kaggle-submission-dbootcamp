# kaggle-submission-dbootcamp
Anna Wang and Max Reimer, Section 001
This repository includes one simple model notebook and one complex model notebook. 
The simple model notebook uses multiple quantitative features and uses a linear regression to predict the sales price. The rmse is calculated with train and test data.
The complex model notebook uses multiple qualitative and quantitative features and uses a linear regression with polynomial features to predict the sales price. It uses functions like 
OneHotEncoder, PolynomialFeatures, StandardScaler, and SimpleImputer. The rmse is calculated with train and test data.
